01 / DUAL ENGINE

任务 × 笔记双引擎

写下即管理。flomo 式卡片流笔记支持 Markdown 实时渲染； 笔记里的任务行会被自动提取为真实任务，双链 backlinks 让任务与笔记双向关联、互相回溯。

  • 完成 / 未完成的二元状态，干净不内耗
  • 开始 / 计划 / 截止 / 完成，四种日期语义
  • 循环任务、优先级、子任务拖拽嵌套、多选批量操作
  • 标题内联语法：#标签 + 自然语言日期
  • 卡片流笔记 · Markdown 实时渲染 · 双链 backlinks
  • 笔记任务行自动提取，任务 ↔ 笔记双向关联
NOTE ⇄ TASK / BACKLINK
