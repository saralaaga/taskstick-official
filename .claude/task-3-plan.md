# Task 3 执行方案：重构文案架构

## 背景与目标

### 产品定位变化
**旧定位**：笔记 + 任务双驱动
**新定位**：碎片收集 → AI 整理 → 结构化执行

### 核心 Slogan
**碎片入，清单出。**

### 核心价值主张
1. **多端随时收集**：微信、邮件、语音、截图，任意渠道扔进来
2. **AI 智能整理**：自动识别任务、提取日期、打标签、构建关联
3. **笔记记录思考**：复杂任务推进过程，用笔记记录想法
4. **双链构建网络**：散点成线，碎片不孤立，形成知识网络
5. **清单化执行**：筛选聚合，形成可执行的清单

---

## 文案架构重构

### Hero 区（首屏）

#### 当前版本
```
任务管理 × 笔记双引擎 · 本地优先
日事贴 — 碎片入，清单出。
笔记里的任务行，自动汇入当天。

写笔记时顺手加一行待办，它就成了真正的任务，
可以筛选、可以循环、可以跨端同步。
```

#### 新版本
```
多端收集 × AI 整理 · 本地优先
日事贴 — 碎片入，清单出。
灵感不等人，随手扔进来，AI 帮你理成清单。

微信、邮件、脑子里冒出来的想法，从任意入口扔进来，
AI 自动识别任务、提取日期、打标签，整理成今天能做的清单。
```

**修改原因**：
- 突出"多端收集"而非"笔记双引擎"
- 强调"随手扔"的便捷性
- 明确 AI 的价值：识别、提取、整理

## 文案原则

1. **去 AI 腔调**：
   - ❌ "想法消失之前先入库"
   - ❌ "让任务与笔记双向关联、互相回溯"
   - ✅ "随手扔进来"
   - ✅ "自动识别任务"

2. **具体胜于抽象**：
   - ❌ "捕获灵感，推进为任务"
   - ✅ "微信、邮件、语音、截图"

3. **简洁有力**：
   - 每个功能描述控制在 50 字以内
   - 功能点列表 3-5 条
   - 避免重复表述

4. **口语化**：
   - 使用"扔进来""理成清单"这类日常用语
   - 避免"基于""进而""从而"等书面语
